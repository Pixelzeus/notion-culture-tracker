Personnalisez vos bases Notion, vos correspondances de colonnes et vos templates de page.

🔑 Clé Secrète Notion (Internal Integration Token)

Nécessaire pour inspecter dynamiquement vos bases de données et y créer les pages. Assurez-vous d'avoir partagé vos bases avec cette intégration dans Notion.

Les clés restent stockées uniquement dans la mémoire sécurisée locale de votre navigateur.

🏗️ Architecture des Bases de Données

Choisissez comment organiser vos entrées culturelles dans votre espace Notion.

📁 3 Bases Séparées Recommandé

Une base dédiée pour les Films, une pour les Séries TV et une pour les Jeux Vidéo. Idéal pour des propriétés sur mesure.

📦 Base Unifiée (Culture Tracker) Hybride

Une seule base de données regroupant tous les médias, différenciés par une colonne discriminante (ex: "Type").

⚙️ Configuration de la Base Unifiée

Renseignez l'identifiant de votre base unique et configurez la propriété discriminante Notion (Type ou Catégorie).

ℹ️ Entrez l'identifiant et cliquez sur "Auto-découvrir" pour charger les colonnes.
